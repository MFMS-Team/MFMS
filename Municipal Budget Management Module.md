**Municipal Budget Management Module**



**Overview**



The Municipal Budget Management Module is responsible for capturing, calculating, and reporting departmental budget information within the Municipal Financial Management System (MFMS).







**The module demonstrates:**



Arrays



Functions



Loops



Conditional Statements



Input/Output Handling



Modular Programming







**Features**





**Enter Departmental Budgets**





Capture the allocated budget for each department.



Store values in an array for later processing.







**Enter Departmental Expenditure**





Capture expenditure for each department.



Store values in a parallel array.







**Calculate Remaining Budget**





Compute remaining funds using:



Remaining

=

Budget

−

Expenditure





**Display Budget Information**





For each department, display:



Department number



Budget



Expenditure



Remaining balance



Status (within budget or exceeded)







**Identify Exceeded Budgets**





Check all departments.



Report which departments exceeded their allocated budget.



Display a summary if none exceeded.







**Validation Features**





The system validates:



Number of departments (must be positive).



Budget and expenditure inputs (numeric values).



Expenditure comparison against budget (status message).







**Programming Concepts Demonstrated**





Arrays → Store budgets, expenditures, and remaining balances.



Functions → Modularize tasks (input, calculation, display, validation).



Loops → Iterate through departments.



Conditional Statements → Check if expenditure is within or exceeds budget.



Input/Output → Use scanf and printf for user interaction.



Modular Programming → Separation of logic into reusable functions.
